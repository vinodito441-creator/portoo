# Portfolio Website

file utama:
- index.html
- style.css
- script.js

cara pakai:
1. buka index.html di browser.
2. ganti nama "Vinzz", deskripsi, dan link sosial di index.html.
3. kalau mau upload ke GitHub Pages, upload ketiga file ini ke repository lalu aktifkan Settings > Pages.

website ini dibuat dengan HTML, CSS, dan JavaScript tanpa framework.
